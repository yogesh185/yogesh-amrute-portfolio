# Frontend Design Craft Guidelines

## Core Principles
1. **Distinctive Editorial Identity:** Avoid generic component libraries or SaaS landing page clichés. Every project deserves an art-directed layout, custom type composition, and intentional negative space.
2. **Typography as Structure:** Treat headlines, lead paragraphs, and mono metadata as architectural elements with strict hierarchical contrast.
3. **Restrained Polish:** High-end digital experiences prioritize micro-interactions, subtle caustics, and responsive layout geometry over distracting animations.
4. **Uncontainerized Fluidity:** Avoid boxing human subjects or artistic focal points into rounded card rectangles when they should organically merge with the scene.
