# Yogesh Amrute Portfolio — Asset Curation Standards

## Authentic Photography Preservation
- **Judo Tournament Photo:** Must remain Yogesh's actual, authentic competition photograph (`martial-arts-original.png`). NEVER replace with AI-generated fighters or models.
- **Yogesh Portrait:** Seated in black jacket and white T-shirt (`hero-portrait.png`). Maintain real facial identity and proportions.
- **About Portrait:** Genuine profile orientation (`about-portrait.png`).

## Project Image Integrity
- Each project must map strictly to its actual or dedicated screenshots:
  - `Intrust India`: E-commerce / merchant dashboard preview.
  - `Aadi Seeds`: Agricultural catalog & crop preview.
  - `YARVO.agency`: 3D crystal asset and studio branding.
  - `Doc AI`: Dedicated document ingestion, QA citations, and RAG interface. NEVER use NEXUS or Intrust mockups for Doc AI!
- Independent concepts (`AVARA`, `ORBIT`, `NEXUS`) must use dedicated concept visuals and be explicitly labeled as independent research.
- Never use a full moodboard collage as a page background or project card.
