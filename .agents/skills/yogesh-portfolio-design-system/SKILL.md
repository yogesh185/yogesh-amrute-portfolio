# Yogesh Amrute Portfolio — Design System Standards

## Dual-Theme Art Direction
- **Dark Theme (Midnight Cinema):**
  - Background: `#080D1B`
  - Secondary background: `#0D1428`
  - Surfaces: `#111B33`, `#162442`
  - Primary text: `#F5F4F0`
  - Secondary text: `#AAB4C8`
  - Accent cobalt: `#315CFF`
  - Electric blue: `#79A7FF`
  - Highlight lime: `#B7FF4A`
- **Light Theme (Editorial Design Studio):**
  - Background: `#F3F0E9`
  - Secondary background: `#EBE8E1`
  - Surfaces: `#FFFEFA`, `#EAE6DD`
  - Primary text: `#17191D`
  - Secondary text: `#686C75`
  - Accent cobalt: `#315CFF`
  - Highlight: `#A5E83E`

## Core Typography
- Display / Headings: `Playfair Display` serif (with Georgia fallback) for artistic editorial titles.
- Interface & Body: `Plus Jakarta Sans` / `General Sans` / `Geist` sans-serif for high legibility.
- Code & Small Metadata: `Geist Mono` for technical labels, timestamps, and commit hashes.

## No Screen-Numbering Rule
- Mockup annotations (e.g. `01 // DIRECTORY`, `Screen 03`, `Screen 08 // LIFE BEYOND TECH`) must NEVER appear in public user-facing UI.
- Use natural editorial labels: `Selected Work`, `About Yogesh`, `Concept Lab`, `YARVO.agency`, `Life Beyond the Screen`, `Contact`.

## Project Classification Standards
- **Real Client / Venture / Shipped Work:**
  - `Intrust India`: Platform & business operations.
  - `Aadi Seeds`: Agriculture client presence.
  - `YARVO.agency`: Yogesh's creative tech venture.
  - `Doc AI`: Built RAG document intelligence project.
- **Independent Concepts (Exploratory Prototypes):**
  - `AVARA`: Avatar communication & voice companion.
  - `ORBIT`: Personal contextual intelligence.
  - `NEXUS`: Unified digital identity & lifestyle.
  - *Must always feature prominent concept disclaimers; never describe as launched clients or shipped companies.*
