# Yogesh Amrute — Personal Portfolio

A cinematic, editorial personal portfolio and product showcase for **Yogesh Amrute** — Full-Stack Engineer, AI Builder, Creative Technologist, and Founder of [YARVO.agency](https://yarvo.agency).

Built with **Next.js 16 (App Router)**, **React 19**, **Tailwind CSS v4**, **Framer Motion**, and **TypeScript**.

---

## ✨ Features

- **Multi-Page Architecture:** Discrete, dedicated pages matching the 9 screens from the design reference:
  - **`/` — Home:** Cinematic Hero with uncontainerized floating portrait, signature iridescent cobalt-blue 3D ribbon, editorial typography, and the Selected Spaces directory.
  - **`/about` — About Me:** Profile portrait with electric ribbon swoosh, core craft philosophy, and live stats.
  - **`/work` — Work:** Project catalog with interactive filters (`All`, `Web`, `Product`, `AI`) showcasing Intrust India, Aadi Seeds, YARVO.agency, and Doc AI.
  - **`/work/[slug]` — Case Studies:** Deep-dive case study layouts with problem/solution breakdowns, metrics, and live site links.
  - **`/experiments` — Concept Lab:** Interactive prototype showcases for AVARA (AI companion), ORBIT (personal intelligence), and NEXUS (connected lifestyle) with carousel pagination.
  - **`/studio` — YARVO.agency:** Studio venture spotlight with glowing 3D crystal polyhedron and capability capsules.
  - **`/beyond-tech` — Life Beyond Tech:** 2×2 authentic photo grid featuring acoustic guitar, football goalkeeping, Yogesh's authentic tournament Judo competition photograph, and chess strategy.
  - **`/contact` — Contact:** Mountain dusk silhouette atmosphere, verified contact links, and interactive note dispatcher.
- **Dual-Theme Art Direction:**
  - **Midnight Cinema Dark Mode:** Deep obsidian (`#080D1B`), electric blue glow (`#315CFF`), and lime accents (`#B7FF4A`).
  - **Editorial Studio Light Mode:** Warm ivory (`#F3F0E9`), crisp paper surfaces (`#FFFEFA`), and dark typography (`#17191D`).
  - Persistent preference in `localStorage` with zero flicker.
- **Uncontainerized Portrait Presentation:** Feathered radial gradient masks and multi-directional edge dissolves allowing the hero portrait to bleed naturally into the ambient canvas.
- **Authentic Assets:** Real Judo tournament competition photograph, guitar soundboard, football pitch, wooden chess set, and project mockups.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ (tested with Node 20 / 22 / 24)
- npm or pnpm

### Installation

```bash
git clone https://github.com/yogesh185/yogesh-amrute-portfolio.git
cd yogesh-amrute-portfolio
npm install
```

### Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port displayed in your terminal).

### Production Build

```bash
npm run build
npm start
```
